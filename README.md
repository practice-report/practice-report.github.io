
Проект Метаморфоза исходит из потенциальной возможности
преобразования исследователя. Начальный способ мышления, с
которым исследователь рождается в этом мире, не является
единственно возможным, представляя собой временную форму,
которая может быть преобразована.

Проект не даёт готовых ответов, не даёт опору, но является
инструментом, переданным одним исследователем другому равному
исследователю.

Проект Метаморфоза имеет соответствие формы, структуры и
содержания. У проекта отсутствует формальный автор (юридический
отказ от авторства и прав в виде лицензии CC0). Проект —
общественное достояние, без возможности обратной связи,
пожертвований и прочих взаимодействий.

                 ------------------------

The Metamorphosis project proceeds from the potential for the
researcher's transformation. The initial mode of thinking, with
which the researcher is born into this world, is not the only
possible one, representing a temporary form that can be
transformed.

The project gives no ready-made answers, gives no support, but
is a tool transmitted by one researcher to another equal
researcher.

The Metamorphosis project has a correspondence of form,
structure, and content. The project has no formal author (a
legal waiver of authorship and rights via the CC0 license). 
The project is in the public domain, with no possibility of
feedback, donations, or other interactions.
